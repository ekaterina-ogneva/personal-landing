# Personal Landing

Персональный лендинг-резюме по фронтенд-разработке.

## Проекты
- **Personal Landing** — персональный лендинг-резюме  
  👉 [https://ubiquitous-melomakarona-1e4c10.netlify.app](https://ubiquitous-melomakarona-1e4c10.netlify.app)

- **Todo App** — приложение для управления задачами с localStorage  
  👉 [https://todo-app-ekaterina.netlify.app](https://todo-app-ekaterina.netlify.app)

- **Weather App** — погода по городам (на моках)  
  👉 [https://weather-app-ogn.netlify.app](https://weather-app-ogn.netlify.app)

## Стек
- **HTML5**: семантическая разметка, доступность (a11y)
- **CSS3**: Flexbox, Grid, медиазапросы
- **JavaScript**: DOM, события, localStorage
- **Инструменты**: Git, GitHub, Netlify

## Как запустить
1. Скачайте репозиторий  
2. Откройте файл `index.html` в браузере

## Особенности
- Адаптивный дизайн (работает на телефоне и десктопе)  
- Соответствует стандартам доступности (a11y)  
- Форма обратной связи через Netlify Forms  
- Поддержка тёмной/светлой темы
